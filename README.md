# 文字角色扮演冒险游戏 (Text RPG Adventure Game)

一个基于Python的文字冒险游戏，包含完整的RPG元素。提供文字版和图形界面两种游戏模式！

## 项目结构

```
text_rpg_game/
├── src/                    # 源代码目录
│   ├── __init__.py        # 包初始化
│   ├── models/            # 游戏模型
│   │   ├── __init__.py
│   │   ├── player.py      # 玩家类
│   │   ├── enemy.py       # 敌人类
│   │   ├── item.py        # 物品类
│   │   └── location.py    # 地点类
│   ├── game_engine.py     # 游戏引擎核心逻辑
│   └── gui.py             # GUI界面组件
├── game.py                # 命令行版本入口（原版）
├── game_gui.py            # GUI版本入口（原版）
├── game_cli.py            # 命令行版本（使用新结构）
├── game_new_gui.py        # GUI版本（使用新结构）
├── requirements.txt       # 项目依赖
├── README.md              # 项目说明
└── 运行说明.md            # 运行指南
```

## 功能特点

### 核心系统
- 🎮 **角色系统** - 等级、经验值、属性成长
- 🗺️ **世界探索** - 多个地点可探索
- ⚔️ **战斗系统** - 回合制战斗，攻击/防御机制
- 🎒 **物品系统** - 可拾取和使用物品
- 💰 **经济系统** - 金币收集
- 📈 **成长系统** - 击败敌人获得经验升级

### 游戏内容
- 5个可探索地点（新手村、迷雾森林、黑暗洞穴、古老遗迹、雪山顶峰）
- 5种敌人（野狼、蝙蝠、洞穴巨魔、骷髅战士、冰霜巨龙）
- 多种物品（治疗药水、武器等）

## 游戏机制

### 角色属性
- **生命值 (HP)**: 当前/最大生命值
- **攻击力**: 影响造成的伤害
- **防御力**: 减少受到的伤害
- **等级**: 通过获得经验值提升
- **金币**: 击败敌人获得

### 升级系统
- 每100经验值升1级
- 升级时提升：
  - 最大生命值 +20
  - 攻击力 +5
  - 防御力 +2
  - 生命值完全恢复

### 战斗系统
- 回合制战斗
- 伤害计算：实际伤害 = 攻击力(±随机) - 防御力
- 可以使用物品或尝试逃跑
- 逃跑成功率50%

## 游戏流程

1. **创建角色** - 输入角色名字
2. **探索世界** - 在不同地点间移动
3. **收集物品** - 拾取有用的物品
4. **战斗成长** - 击败敌人获得经验和金币
5. **最终挑战** - 击败雪山顶峰的冰霜巨龙通关
